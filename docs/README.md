# unweird docs

Read them in order the first time, after that jump around.

1. [Getting started](getting-started.md) — set up a project, open a window
2. [Screens and components](screens-and-components.md) — how a UI is put together, navigation, sidebars
3. [Layout](layout.md) — what goes where, and how to change it
4. [Widgets](widgets.md) — everything you can put on a screen
5. [State and events](state-and-events.md) — live text, background work, timers, shortcuts, focus
6. [Dialogs and toasts](dialogs-and-toasts.md)
7. [Styling](styling.md) — themes, button and text styles
8. [Your own widgets](custom-widgets.md) — drawing, input, raw OpenGL
9. [Installing content](installing-content.md) — `unweird-install`
10. [3D](3d.md) — `unweird-3d`
11. [Games](games.md) — `unweird-game`: 2D and 3D games from a few classes

The demo app in `example/` uses almost everything here. If something is unclear, look at how it does it.
