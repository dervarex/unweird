# 3D

```kotlin
unweird { threeD = true }
// or: implementation("com.github.dervarex.unweird:unweird-3d:v0.2.0")
```

A 3D view is a normal widget. It sits in the layout, scrolls with the page, has rounded corners.

```java
public class ModelScreen extends Screen {
    Text heading = new Text("Model");

    View3D view = new View3D(new Scene()
                    .add(new Node(Mesh.box(1, 1, 1), Material.color(Color.hex("#7c6cff")))))
            .camera(Camera.orbit(0, 0, 0, 5).angles(30, 20))   // target x, y, z, distance; yaw, pitch
            .height(360);
}
```

Mouse: left-drag turns, right-drag moves, wheel zooms. Focused: arrow keys and +/-. Android: drag turns.

Full example: [3D view](/examples/cube).

## View3D

| | |
|---|---|
| `View3D(scene)` | |
| `camera(Camera)` / `camera()` | |
| `height(px)` | It takes the full width |
| `autoRotate(degreesPerSecond)` | Pauses while dragging |
| `controls(false)` | No mouse/keyboard camera control |
| `onFrame(seconds -> ...)` | Every frame, for animation |
| `onClick((hit, button) -> ...)` | Only real clicks; drags don't count |
| `pick(x, y)` | What's under a window position |

## Scene and nodes

A `Node` is a mesh + material + position/rotation/scale + children. Children move with their parent.

```java
Node body = new Node(Mesh.box(1, 1.5f, 0.5f), skin);
Node shoulder = Node.group().position(0.75f, 0.7f, 0);             // the pivot
Node arm = new Node(Mesh.box(0.5f, 1.5f, 0.5f), skin).position(0, -0.6f, 0);
shoulder.add(arm);
body.add(shoulder);

view.onFrame(t -> shoulder.rotation((float) Math.sin(t * 6) * 30, 0, 0));   // swings around the shoulder
```

| `Node` | |
|---|---|
| `position(x, y, z)` / `rotation(xDeg, yDeg, zDeg)` / `scale(s)` / `scale(x, y, z)` | Relative to the parent |
| `rotation(Quaternionf)` | |
| `visible(false)` | Hides it and its children |
| `mesh(Mesh)` / `material(Material)` | Swap |
| `add(...)` / `remove(node)` / `children()` / `descendants()` | |
| `name("arm")` | For your own lookups |

| `Scene` | |
|---|---|
| `add(...)` / `remove(node)` / `root()` | |
| `sun(x, y, z)` | Light direction |
| `ambient(0.5f)` | Light from everywhere |
| `background(color)` | Transparent by default (the page shows through) |

Y is up, the default camera looks from +Z.

## Camera

```java
Camera.orbit(0, 1, 0, 6)       // look at (0, 1, 0) from 6 units away
        .angles(30, 20)        // yaw, pitch in degrees
        .fov(50)
        .zoomLimits(2, 20);
```

## Meshes

```java
Mesh.box(w, h, d);
Mesh.box(w, h, d, Mesh.BoxUv.of(u, v, w, h, d, 64, 64));   // "box UV" layout (Blockbench, skins)
Mesh.plane(w, d);
```

Your own:

```java
Mesh.Builder b = Mesh.builder();
int a = b.vertex(0, 0, 0,  0, 0, 1,  0, 1, Color.WHITE);   // position, normal, uv, color
int c = b.vertex(1, 0, 0,  0, 0, 1,  1, 1, Color.WHITE);
int d = b.vertex(0, 1, 0,  0, 0, 1,  0, 0, Color.WHITE);
b.triangle(a, c, d);
Mesh triangle = b.build();
```

`b.quad(...)`, `b.box(...)` and, for block worlds, `b.blockFace(x, y, z, Mesh.BlockFace.UP, color)`.

Meshes are immutable. Changed something? Build a new one and `node.mesh(newMesh)`. The old GPU data is freed on
its own.

## Materials and textures

```java
Material.color(Color.hex("#ff0000"));
Material.texture(Texture.resource("/skins/me.png").nearest())   // nearest = sharp pixels
        .cutout()        // see-through pixels are holes
        .transparent()   // real blending, drawn after the rest
        .doubleSided()
        .unlit()
        .tint(Color.hex("#ffcccc"));
```

| `Texture` | |
|---|---|
| `resource(path)` / `file(path)` / `url(url)` | `url` loads in the background |
| `of(Pixels)` / `blank()` | |
| `set(pixels)` / `load(url)` | Replace the picture; the view picks it up next frame |
| `width()`, `height()`, `argb(x, y)`, `problem()` | |

`Pixels.of(bufferedImage)` on desktop, `Pixels.fromArgb(w, h, argb)` or `Pixels.decode(bytes)` anywhere.

## Clicking things

```java
view.onClick((hit, button) -> {
    if (hit == null) return;              // empty space
    hit.node(); hit.point(); hit.normal(); hit.distance();
});
```

For block worlds, `hit.block()` is the block you clicked and `hit.blockInFront()` is where a new one would go.
`view.pick(x, y)` and `scene.pick(ray)` do the same on demand.
