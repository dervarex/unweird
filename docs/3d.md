# 3D (`unweird-3d`)

```kotlin
implementation("com.github.dervarex.unweird:unweird-3d:v0.1.1")
```

A 3D view is a normal widget. It sits in the layout, scrolls with the page, has rounded corners.

```java
Scene scene = new Scene()
        .add(new Node(Mesh.box(1, 1, 1), Material.color(Color.hex("#5fae3e"))));

View3D view = new View3D(scene)
        .camera(Camera.orbit(0, 0, 0, 5).angles(30, 20))   // target x,y,z, distance; yaw, pitch
        .height(360);
```

Mouse: left-drag turns, right-drag moves, wheel zooms. Focused: arrow keys and +/-.

## Scene

- `Node` = mesh + material + position/rotation/scale + children. Children move with their parent, so to swing an
  arm around its shoulder, make the shoulder a parent node and offset the arm in a child.
- `node.position(x, y, z)`, `node.rotation(xDeg, yDeg, zDeg)`, `node.scale(s)`, `node.visible(false)`.
- `scene.sun(x, y, z)` light direction, `scene.ambient(0.5f)`, `scene.background(color)` (transparent by default).

Y is up, the default camera looks from +Z.

## Meshes

```java
Mesh.box(w, h, d);
Mesh.box(w, h, d, Mesh.BoxUv.of(u, v, w, h, d, 64, 64));   // "box UV" layout, like Blockbench / skins
Mesh.plane(w, d);

Mesh.Builder b = Mesh.builder();
b.quad(...); b.triangle(...); b.vertex(...);
b.blockFace(x, y, z, Mesh.BlockFace.UP, color);              // for block worlds
Mesh mesh = b.build();
```

Meshes are immutable. Changed something? Build a new one and `node.mesh(newMesh)`. Old GPU data gets freed by itself.

## Materials and textures

```java
Material.color(Color.hex("#ff0000"));
Material.texture(Texture.resource("/skins/me.png").nearest())   // nearest = sharp pixels
        .cutout()        // see-through pixels are holes
        .transparent()   // real blending, drawn after the rest
        .doubleSided()
        .unlit();
```

Textures come from `resource`, `file`, `url` (background) or a `BufferedImage`. `texture.set(image)` swaps the
picture, the view picks it up next frame.

## Animation

```java
view.autoRotate(20);                              // degrees per second, pauses while dragging
view.onFrame(t -> arm.rotation((float) Math.sin(t * 6) * 30, 0, 0));
```

## Clicking things

```java
view.onClick((hit, button) -> {
    if (hit == null) return;              // clicked into empty space
    hit.node(); hit.point(); hit.normal();
});
```

Only real clicks count; dragging to turn the camera doesn't fire it. For block worlds, `hit.block()` is the block
you clicked and `hit.blockInFront()` is where a new one would go.

`view.pick(x, y)` and `scene.pick(ray)` do the same on demand.
